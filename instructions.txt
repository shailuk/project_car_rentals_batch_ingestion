Data from car_rentals and customer files are loaded into the dimensions table in snowflake. (SCD Type 2)
Data is then inserted into fact table (SCD Type 2)  

Step 1 : Create S3 bucket and 2 folders within it - 1) car_rental_daily_data   2) customer_daily_data

Step 2 : Create a new database - 'car_rental' in snowflake

Step 3 : Run the SQL scripts to create dimension and fact tables. Insert dummy data

Step 4 : Create file format type, storage integration and stage

    You actually don't attach the policy to the EMR Serverless Application itself.

In AWS EMR Serverless, applications are just empty compute shells. 
They don't hold permissions. Instead, you attach the policy to the IAM Role you 
just created, and then you pass that role to the application at the exact moment
you submit your job via Airflow.
